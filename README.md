# Instalaciones Sanitarias — Entorno Virtual 3D Rayos X e Isométricos

Visor interactivo web para explorar en tiempo real las instalaciones sanitarias de la vivienda multifamiliar de tres pisos más azotea (San Martín de Porres, Lima), desarrollado para el curso de **Instalaciones Sanitarias** (Docente: Ing. Aybar Galdos Josúe Alcibiades).

## Funcionalidades

- **Entorno 3D Modo Rayos X (WebGL2 + Three.js HDR Bloom)**: Estructura translúcida extraída desde el plano arquitectónico real, con las seis especialidades en colores fosforescentes brillantes (`Agua Fría`, `Agua Caliente CPVC`, `Desagüe`, `Ventilación`, `Aguas Pluviales` y `Contra Incendios`), navegación por pisos e inspección interactiva por clic de cada tramo, válvula compuerta (`0.30 × 0.60 m`), therma `80 L`, caja de registro `CR-1..4`, sumidero pluvial y extintor.
- **Visor Vectorial de Isométricos y Planos CAD (`SVG`)**: Acceso directo con zoom infinito y arrastre sobre las láminas `IS-01`, `IS-02`, `IS-03` e `IS-04` con sus líneas normativas según el **RNE IS.010 Anexo N° 10**.
